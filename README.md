# 小贴（Xiaotie）

一个本地运行的 macOS 剪贴板历史工具，原生 Swift（AppKit + SwiftUI）编写，常驻菜单栏。开源不收费。

所有数据只保存在本机 `~/Library/Application Support/Xiaotie/`（`history.json` 存文字记录，`images/` 存图片），不联网、不上传。

## 功能

- 自动记录复制的文字、图片（截图、网页图片）、在访达里复制的文件
- 重复复制同一内容会自动去重并移到最前
- `⌘⇧V` 唤出浮动面板：搜索（支持中文输入法）、键盘选择、回车直接粘贴到当前应用
- 右侧预览完整文字 / 大图 / 文件路径
- 收藏常用内容，收藏的不会被自动清理
- 收藏可以打多个标签，标签就是分类：收藏页按分类筛选，菜单栏里按分类浏览，搜索时输入 `#标签` 直接筛选
- 自动跳过密码管理器（1Password、Bitwarden、钥匙串、系统「密码」等）复制的内容
- 菜单栏快速访问最近 12 条，以及暂停记录、开机启动、快捷键、保存条数等设置

## 安装

需要 macOS 13+，以及 Xcode 或命令行工具（没有的话先运行 `xcode-select --install`）。

```bash
git clone https://github.com/YoungCan-Wang/xiaotie.git
cd xiaotie
bash build.sh install
```

会编译、安装到 `/Applications` 并自动启动。只编译不安装：`bash build.sh`，产物在 `build/小贴.app`。

从旧版本升级：安装时会自动关掉并替换以前的 ClipKeeper 和 Electron 版小贴，历史记录、收藏和设置会自动迁移过来。升级后需要重新开启一次辅助功能权限和「开机自动启动」；系统设置 → 通用 → 登录项 里如果还留着 ClipKeeper，删掉即可。

## 面板快捷键

| 按键 | 作用 |
| --- | --- |
| 直接打字 | 搜索 |
| `↑` `↓` | 选择 |
| `⏎` | 粘贴到当前应用 |
| `⇧⏎` | 只复制到剪贴板，不粘贴 |
| `⌘1` – `⌘9` | 直接粘贴第 1–9 条 |
| `⌘S` | 收藏 / 取消收藏 |
| `⌘T` | 编辑标签（打了标签会自动收藏） |
| `⌘D` | 删除 |
| `Tab` | 在「全部」和「收藏」之间切换 |
| `←` `→` | 在收藏页切换分类（搜索框为空时） |
| `Esc` | 关闭 |

鼠标单击某条也会直接粘贴，右键有更多操作（收藏、编辑标签、添加到已有分类、删除）。

## 收藏与分类

- 选中一条按 `⌘T`，输入标签，多个标签用空格或逗号分隔，比如 `工作 代码`；已有的标签可以直接点选
- 打了标签的内容会自动收藏；一条内容可以属于多个分类
- 收藏页顶部是分类条：全部收藏 / 未分类 / 各个标签，点一下就筛选；右键标签可以重命名或删除（重命名成已有名字会合并）
- 在任何页面搜索 `#工作` 只看带「工作」标签的内容，也可以和关键词一起用：`#代码 docker`
- 菜单栏图标 → 收藏，按分类展开浏览
- 菜单栏菜单里，右键点某条（或按住 `⌥` 再点）就是收藏 / 取消收藏，菜单栏图标会闪一下星星如果 `⌘⇧V` 和某些应用的「粘贴并匹配样式」冲突，可以在菜单栏图标里换成 `⌥⌘V` 等。

## 权限

- **辅助功能**：自动粘贴需要（系统设置 → 隐私与安全性 → 辅助功能）。不给也能用，选中后内容已在剪贴板里，自己按 `⌘V` 即可。
- 系统的授权是跟着应用签名走的。`build.sh` 会优先用钥匙串里的开发者证书（Apple Development 等，Xcode 登录过 Apple ID 一般就有）签名，签名固定，以后重新编译不用再授权；第一次用证书签名时系统可能弹窗问 codesign 能否使用钥匙串，选「始终允许」。
- 没有证书时用本地临时签名，每次重新编译签名都会变，系统设置里旧的授权看着是开的其实已失效。`build.sh install` 会自动清掉失效的授权；也可以点菜单栏里的「⚠️ 辅助功能权限未生效…」重新授权。
- 苹果预告以后的 macOS 会在应用读取剪贴板时询问权限，看到「允许 小贴 从其他应用粘贴」之类的提示时选允许。

## 卸载

菜单栏图标 → 退出小贴，然后删除：

```
/Applications/小贴.app
~/Library/Application Support/Xiaotie/
```

## 项目结构

```
Sources/
  main.swift              入口
  AppDelegate.swift       菜单栏图标、设置、粘贴流程
  ClipboardMonitor.swift  监听系统剪贴板
  ClipboardStore.swift    历史记录的增删改与持久化
  PanelController.swift   浮动面板、键盘操作
  HistoryView.swift       面板界面（SwiftUI）
  HotKey.swift            全局快捷键（Carbon）
  Paste.swift             写回剪贴板、模拟 ⌘V
  Images.swift            图片保存与缩略图缓存
  Models.swift            数据模型、设置
Resources/Info.plist
Scripts/make_icon.swift   生成应用图标
build.sh                  编译打包脚本
```
